# images.camelianguyen.fr

Images des articles du blog de camelianguyen.fr (Kit) et de leurs épingles Pinterest.

- `icones/` : les icônes du kit Papier Pivoine (palette du site), partagées par tous les articles.
- `blog/AAAA-MM-JJ-adresse-de-l-article/` : les images d'un article et ses épingles.

On ajoute, on ne supprime jamais : les articles Kit et les épingles pointent vers ces adresses.
